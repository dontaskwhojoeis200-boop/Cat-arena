# Windows development roadmap (superseded)

This file held the N8–N20 plan written for the 2026-11-12 handoff (Windows-only, 480 MiB combined
memory, late-2000s art direction). The revised handoff of 2026-11-16 replaced it: 192 MiB combined
memory (128 MiB CPU + 64 MiB GPU), Quake III Arena-inspired art, Vulkan 1.1 intended baseline.

The current roadmap is [ROADMAP_N8_N20.md](ROADMAP_N8_N20.md). The earlier text is in git history
(branch `n9-windows`, commit 525adc5).
